## What failed, and how it was corrected

1. **Ponytail ships its own AGENTS.md.** Replacing ours would have deleted the session protocol. Used the Cursor adapter instead. Rationale: `docs.md`.
2. **`embed_texts` originally `SystemExit`s.** That would have killed the API process on Ollama-down during a question. Changed to `EmbedError`; CLI still exits, retrieval falls back to sparse-only.
3. **README said first boot auto-ingests.** It doesn't. Corrected to an explicit `python scripts/ingest.py`.
4. **`DATABASE_URL` / `OLLAMA_BASE_URL` in `.env.example` used Docker hostnames.** Host ingest would have pointed at `postgres` and `host.docker.internal`. Split: `.env.example` is localhost for host scripts; compose overrides for the backend container.
5. **`docker compose config` failed without `.env`.** `env_file` is now optional so a fresh clone still validates. Chat still needs `GROQ_API_KEY`.
